# Artifact evaluation checklist

- PRD/requirements: scope, non-goals, `REQ-*`, acceptance criteria.
- Architecture/ADR: boundaries, alternatives, consequences, trace links.
- UI/UX/component map: states, responsive/accessibility, implementation guidance.
- Plan/task pack: dependencies, acceptance, verification, allowed scope.
- Research brief: primary evidence, freshness, confidence, trade-offs.
- Implementation handoff: changes, checks, runtime evidence, unknowns, next action.
