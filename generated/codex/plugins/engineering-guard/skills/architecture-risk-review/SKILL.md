# Architecture risk review

Evaluate boundary compliance, data ownership, API contracts, migrations, dependency health, obvious security exposure, performance risks, and operability. Treat repository/source evidence as stronger than assumptions; state unknowns explicitly.

Do not redesign architecture or mandate a full security/performance program. Exit with actionable severity-tagged findings.
