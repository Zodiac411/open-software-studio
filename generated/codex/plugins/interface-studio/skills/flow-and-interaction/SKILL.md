# Flow and interaction

Define goals, information architecture, routes/screens/panels/modals, user flow, and stateful interaction: loading, empty, error, disabled, success, offline when relevant, keyboard, pointer, and touch. Include responsive/mobile consequences.

Do not choose decorative styling before behavior is clear. Exit with implementation-ready interaction and screen-map decisions.
