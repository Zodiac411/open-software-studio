# Visual QA

Check hierarchy, spacing, component consistency, states, responsive behavior, accessibility, and reference fidelity. Flag generic layouts, excessive cards/gradients/glass, decorative complexity, and unexplained drift. Define screenshot/runtime evidence required for a future implementation gate.

Do not claim visual fidelity without supplied reference/runtime evidence. Exit with prioritized corrections and unverified items.
