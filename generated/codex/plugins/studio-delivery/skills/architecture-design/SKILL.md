# Architecture design

Map responsibilities, modules, data/state flow, persistence, integration/API boundaries, deployment, security/reliability, and failure modes to requirements. Record material choices as concise `ADR-*` records with alternatives and consequences. Respect approved UX and existing repository constraints.

Do not redesign merely to be cleaner. Exit with decision links and unresolved risks.
