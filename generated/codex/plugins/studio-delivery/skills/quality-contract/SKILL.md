# Quality contract

Use only for long autonomous work or an explicit quality floor. Write the few non-negotiable checks, owner, and evidence location. Treat skips, suppressions, threshold reductions, and weakened checks as changes needing explicit justification.

Do not use on normal short work. Exit with a small durable contract. Reject: adding generic standards because a task is long.
