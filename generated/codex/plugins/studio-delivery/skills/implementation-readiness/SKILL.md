# Implementation readiness

Check clarity, consistency, dependencies, API/data boundaries, UX states, constraints, acceptance criteria, risks, and traceability. Identify only gaps that could cause rework or unsafe assumptions.

Do not produce a replacement plan. Exit with BLOCKING/IMPORTANT/OPTIONAL findings and a go/no-go recommendation.
