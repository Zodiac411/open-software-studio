# Web App Builder router

Execution Guard governs how work proceeds. Read project instructions/artifacts, then route first to `repo-intake`; route implementation to `implementation-and-integration`, unexpected failures to `debugging-and-verification`, and completion to structured handoff. Delegate only independent bounded packages.

Do not silently redesign approved UI/architecture or apply every subagent. Exit with a package, change scope, and success checks.
