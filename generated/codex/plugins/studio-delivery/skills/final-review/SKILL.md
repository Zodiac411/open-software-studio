# Final review

Review requirement fit, correctness, edge cases, scope, reuse, compatibility, test quality, and check weakening. Trace each changed hunk to the task. Report unrelated optional improvements without silently fixing them.

Do not use as a cleanup license. Exit with blocking findings fixed or explicitly carried into Prove It. Reject: “while here” changes outside the requirement.
