# Prove It

**DEFINE** the requested outcome and decisive evidence. **BREAK** the claim with relevant failure/edge probes. **VERIFY** the direct result, not merely a proxy. Return exactly one verdict: `PROVEN`, `FAILED`, `NOT PROVEN`, or `BLOCKED`.

Never call a task fully complete on `NOT PROVEN` or `BLOCKED`. Do not accept a zero exit code as proof by itself. Exit with the verdict, commands/observations, and remaining uncertainty.
