# Execution Guard router

Apply `pragmatic-core`. Classify the task as tiny, normal, multi-file/risky, version-sensitive, failing, long-running, or completion. Load only the matching specialist: context, source/reuse, incremental build, behavior test, root-cause debug, final review, quality contract, or handoff. Always finish a substantive task in `prove-it`.

Do not use this to replace a domain workflow or turn a bounded edit into process ceremony. Evidence exit: selected skills have a concrete next action and no unjustified specialist is loaded.
