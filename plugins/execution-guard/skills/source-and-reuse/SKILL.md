# Source and reuse

Use for framework questions, dependencies, version-sensitive APIs, or new helper proposals. Inspect installed version, local conventions, and existing capabilities. Consult exact authoritative docs when available. State why each higher-preference option was insufficient before creating code.

Do not use for behavior already proven in local code. Exit with a grounded choice and source/version evidence. Reject: “I know this API” when version is unknown.
