# Execution Guard

Execution Guard is the renamed implementation of the supplied Seatbelt design handoff. It is a skills-only, Codex-gated discipline layer with no MCP server, app, hook, daemon, telemetry, automatic git action, or external dependency.

Recommended Codex instruction:

> For every substantive task, route through the Execution Guard plugin before acting. Its pragmatic-core always applies; load only specialists justified by phase and risk. Explicit user and repository instructions outrank it. Before claiming substantive work complete, use Prove It. If evidence is insufficient, report NOT PROVEN or BLOCKED.

“Always” means route, not ritual. A one-line bounded edit should usually load only `pragmatic-core` and `prove-it`.
