# Traceability and handoff

Link `REQ -> ADR -> UX -> TASK -> change -> TEST/evidence` where it adds decision value. Audit stale/contradictory documents and broken references. For serious handoffs use the shared template: goal, state, work, decisions, files, constraints, problems, uncertainty, evidence, next action, done definition.

Do not turn chat logs into a project database. Exit with missing links/staleness explicitly marked.
