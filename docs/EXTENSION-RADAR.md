# Extension radar

| Project | Purpose | Why considered | Why excluded | Reconsider when |
|---|---|---|---|---|
| Penpot / Penpot MCP | open design collaboration | strong open alternative to proprietary design platforms | core UI artifacts work without a live design server | a workspace has a verified Penpot deployment |
| Storybook | component inventory and visual review | excellent component evidence surface | requires project-specific setup | a target repo already uses Storybook |
| SearXNG | self-hosted web search | open research integration | not needed for native web research; adds hosting | reproducible self-hosted research is required |
| Playwright | browser automation | open runtime/browser verification | target projects choose their own setup | a web repo needs browser verification |
| shadcn registries | reusable UI components | supports reuse-first implementation | no registry should be mandatory | repository declares a compatible registry |
| OpenPencil | open UI tooling | useful visual artifact enhancement | current core needs portable specs first | its current integration and license are verified for the target workspace |
